# Release Checklist — Smart Cabinet Assistant

- [ ] `versionCode` از نسخه قبلی بالاتر است.
- [ ] `versionName` به‌روز است.
- [ ] `applicationId = com.mdfchi.app` تغییر نکرده است.
- [ ] Build Release در CI موفق است.
- [ ] APK با همان Signing Key خصوصی امضا شده است.
- [ ] امضای v1/v2/v3 Verify شده است.
- [ ] SHA-256 APK ثبت شده است.
- [ ] Certificate SHA-256 با نسخه قبلی تطبیق دارد.
- [ ] پروژه‌های نسخه قبلی بدون حذف اطلاعات Load می‌شوند.
- [ ] Back از صفحه فرعی به صفحه قبلی برمی‌گردد.
- [ ] فرم پروژه جدید مقدار ازپیش‌پرشده ندارد.
- [ ] اعداد فارسی/عربی/لاتین قابل ورود هستند.
- [ ] Cut Optimizer روی داده نمونه تست شده است.
- [ ] Backup/Restore JSON تست شده است.
- [ ] CSV و PDF روی دستگاه واقعی تست شده‌اند.
- [ ] README / CHANGELOG / MARKET_DESCRIPTION به‌روز هستند.
- [ ] Signing Key و `info.txt` وارد GitHub عمومی نشده‌اند.
