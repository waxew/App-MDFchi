# متن آماده مارکت‌ها — نسخه 3.0.0

## نام برنامه
دستیار هوشمند کابینتسازی

## توضیح کوتاه
دستیار حرفه‌ای کابینت‌سازها؛ محاسبه یونیت و Cut List، بهینه‌سازی برش ورق، MDF/PVC/یراق، قیمت پروژه، PDF و مدیریت پروژه — فارسی و آفلاین.

## توضیح کامل
«دستیار هوشمند کابینتسازی» یک جعبه‌ابزار تخصصی برای کابینت‌سازها، MDFکارها و کارگاه‌هایی است که می‌خواهند محاسبات روزمره، لیست برش و اطلاعات پروژه را یک‌جا و همیشه همراه داشته باشند.

ابعاد پروژه را وارد کنید تا برنامه برای کابینت زمینی، کابینت دیواری، کمد دیواری و یونیت ایستاده لیست قطعات و برآورد مواد مصرفی را آماده کند. ابزارهای جداگانه برای درب، کشو، لولا، طبقات، پشت‌بند، صفحه کابینت، MDF، ورق، PVC، پرت، یراق، دستمزد و قیمت نهایی نیز در دسترس هستند.

در نسخه 3، «بهینه‌ساز برش ورق» قطعات MDF پروژه را با درنظرگرفتن ابعاد ورق، Kerf تیغه و امکان چرخش 90 درجه روی ورق‌ها جانمایی می‌کند. می‌توانید نمودار هر ورق، مختصات قطعات، راندمان و پرت تقریبی را ببینید و قطعاتی را که از ابعاد ورق بزرگ‌تر هستند شناسایی کنید.

پروژه‌ها روی گوشی ذخیره می‌شوند و می‌توانید آن‌ها را جست‌وجو، ویرایش، کپی یا حذف کنید. Cut List را به‌صورت CSV و گزارش کامل پروژه را به‌صورت PDF خروجی بگیرید. Backup کامل JSON نیز امکان انتقال و بازیابی پروژه‌ها و تنظیمات را فراهم می‌کند.

### امکانات اصلی
- کابینت زمینی، دیواری، کمد دیواری و یونیت ایستاده
- تولید Cut List
- ابعاد درب و کشو
- تعداد و محل پیشنهادی لولا
- طبقات، پشت‌بند و صفحه کابینت
- متراژ MDF، ورق و نوار PVC
- پرت و راندمان
- قیمت MDF، یراق، دستمزد و قیمت نهایی
- تبدیل میلی‌متر، سانتی‌متر و متر
- Cut Optimizer با Kerf و Rotation
- نمودار چیدمان قطعات روی ورق
- ذخیره، جست‌وجو، ویرایش و کپی پروژه
- خروجی CSV و PDF
- Backup و Restore JSON
- پشتیبانی از اعداد فارسی/عربی/لاتین
- رابط فارسی RTL و عملکرد اصلی آفلاین

### نکته حرفه‌ای
خروجی‌های برنامه ابزار کمکی کارگاهی هستند. فرمول نهایی می‌تواند با نوع یراق، روش ساخت، ضخامت متریال، رگه ورق و استاندارد هر کارگاه متفاوت باشد. قبل از برش نهایی، اندازه‌ها و مشخصات فنی کنترل شوند.
