# متن آماده برای مارکت‌ها

## نام برنامه
دستیار هوشمند کابینت‌سازی

## توضیح کوتاه
جعبه‌ابزار تخصصی کابینت‌سازها؛ محاسبه یونیت، لیست برش، MDF، ورق، PVC، لولا، یراق، دستمزد و قیمت پروژه — آفلاین و فارسی.

## توضیح کامل
«دستیار هوشمند کابینت‌سازی» برای زمانی ساخته شده که وسط کارگاه، اندازه‌گیری یا قیمت‌گذاری نمی‌خواهید بین چند ماشین‌حساب، دفتر و فایل مختلف جابه‌جا شوید.

ابعاد پروژه را وارد کنید و برنامه به شما کمک می‌کند قطعات یونیت، لیست برش، متراژ MDF، تعداد تقریبی ورق، نوار PVC و اطلاعات موردنیاز ساخت را سریع‌تر محاسبه کنید. برای درب، کشو، طبقات، پشت‌بند، صفحه کابینت و لولا ابزارهای جداگانه در اختیار دارید و بخش مالی نیز هزینه MDF، یراق‌آلات، دستمزد و قیمت نهایی پروژه را جمع‌بندی می‌کند.

پروژه‌های خود را روی گوشی ذخیره کنید، بعداً آن‌ها را ویرایش یا کپی کنید و لیست برش را به‌صورت فایل CSV خروجی بگیرید. اطلاعات اصلی برنامه به‌صورت محلی روی دستگاه نگهداری می‌شود و بیشتر ابزارهای محاسباتی بدون اینترنت کار می‌کنند.

### امکانات اصلی
- محاسبه کابینت زمینی، دیواری، کمد دیواری و یونیت ایستاده
- تولید لیست برش
- محاسبه ابعاد درب و کشو
- پیشنهاد تعداد و محل لولا
- محاسبه طبقات و پشت‌بند
- محاسبه صفحه کابینت
- متراژ MDF و تعداد تقریبی ورق
- محاسبه نوار PVC و پرت ورق
- محاسبه هزینه MDF و یراق‌آلات
- محاسبه دستمزد و قیمت نهایی پروژه
- تبدیل میلی‌متر، سانتی‌متر و متر
- ذخیره، ویرایش و کپی پروژه‌ها
- خروجی CSV لیست برش
- رابط فارسی و آفلاین

### نکته حرفه‌ای
فرمول‌های کارگاهی می‌توانند با نوع یراق، شیوه ساخت، ضخامت متریال و استاندارد هر کارگاه متفاوت باشند. خروجی‌های برنامه ابزار کمکی برای سرعت و کاهش خطای محاسبات هستند و قبل از برش نهایی باید با روش اجرایی کارگاه کنترل شوند.
