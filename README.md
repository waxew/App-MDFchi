# MDFچی — ابزار کابینت‌ساز

MDFچی یک برنامه اندرویدی فارسی و سبک برای محاسبات روزمره کابینت‌سازی و MDF است. رابط برنامه با تم فانتزی ابزار کارگاه طراحی شده و هدف آن انجام سریع محاسبات بدون پیچیدگی اضافی است.

## نسخه فعلی

**1.0.2 — versionCode 3**

## امکانات

- محاسبه ابعاد قطعات یونیت و تولید لیست برش تقریبی
- تخمین تعداد ورق MDF با درصد پرت قابل تنظیم
- محاسبه هزینه ورق، یراق و دستمزد
- ذخیره چند پروژه روی دستگاه
- بررسی نسخه جدید از `version.json`
- منوی همبرگری سمت راست در تمام صفحات
- تنظیمات و بخش اعلان‌ها
- معرفی به دوستان
- درباره ما و تماس با پشتیبانی
- درباره نرم‌افزار با توضیح کوتاه و نمایش نسخه
- ناوبری Back Stack؛ بازگشت به صفحه قبلی و خروج فقط از صفحه اصلی
- رابط فارسی RTL و ظاهر فانتزی با المان‌های متر، پیچ، پیچ‌گوشتی، چکش، اره و MDF

## معماری آپدیت

شناسه نصب برنامه ثابت نگه داشته می‌شود و در هر انتشار `versionCode` افزایش می‌یابد. نسخه‌های پابلیش باید با **همان کلید امضای Release** امضا شوند؛ در این صورت نسخه جدید روی نسخه قبلی نصب می‌شود و اطلاعات `SharedPreferences` باقی می‌ماند.

> کلید خصوصی Signing داخل Repository عمومی ذخیره نشده است. Backup کلید و اطلاعات آن فقط در ZIP خصوصی تحویلی پروژه قرار دارد.

## ساخت پروژه روی لپ‌تاپ

1. پروژه را با Android Studio باز کنید.
2. JDK 17 و Android SDK 35 را نصب/انتخاب کنید.
3. Gradle Sync را اجرا کنید.
4. برای تست از Build معمولی استفاده کنید.
5. برای انتشار، Release را با کلید موجود در پوشه خصوصی `signing/` فایل ZIP تحویلی امضا کنید.

## ساخت خودکار در GitHub

Workflow موجود در `.github/workflows/android-apk.yml` با Push روی `main` یک **unsigned Release APK** می‌سازد و آن را در Actions به‌عنوان Artifact قرار می‌دهد. امضای نهایی خارج از GitHub عمومی انجام می‌شود تا کلید خصوصی افشا نشود.
