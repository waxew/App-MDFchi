# MDFچی — ابزار کابینت‌ساز

نسخه اولیه اپ اندروید MDFچی برای محاسبات روزمره کابینت‌سازی و MDF.

## امکانات نسخه 1.0.0

- محاسبه ابعاد قطعات یک یونیت و تولید لیست برش
- تخمین تعداد ورق MDF با ابعاد پیش‌فرض 183×366 سانتی‌متر
- محاسبه سریع هزینه ورق، یراق و دستمزد
- ذخیره آخرین پروژه روی دستگاه
- بررسی نسخه جدید از فایل `version.json`
- رابط فارسی RTL با ظاهر فانتزی و المان‌های ابزار نجاری

## معماری انتشار و آپدیت

`applicationId` ثابت است: `com.mdfchi.app`.
برای هر انتشار جدید `versionCode` باید افزایش پیدا کند و `versionName` نیز به‌روزرسانی شود. فایل `version.json` نسخه منتشرشده را مشخص می‌کند. داده‌های پروژه در SharedPreferences ذخیره می‌شوند و هنگام نصب نسخه جدید روی نسخه قبلی باقی می‌مانند.

## ساخت APK

GitHub Actions در `.github/workflows/android-apk.yml` با هر Push روی `main` یک APK دیباگ می‌سازد و به‌عنوان Artifact ذخیره می‌کند.
