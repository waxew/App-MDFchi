# دستیار هوشمند کابینت‌سازی

یک اپلیکیشن اندرویدی فارسی، آفلاین و تخصصی برای کابینت‌سازها، MDFکارها و طراحان کارگاهی. نسخه 2 پروژه از یک ماشین‌حساب ساده به یک جعبه‌ابزار کامل برای محاسبه یونیت، لیست برش، مواد مصرفی، یراق، دستمزد، قیمت پروژه و مدیریت پروژه‌های قبلی ارتقا پیدا کرده است.

## نسخه فعلی

**2.0.0 — versionCode 20**

Application ID عمداً همان `com.mdfchi.app` باقی مانده است تا نسخه 2 روی نسخه‌های 1.x به‌عنوان Update نصب شود. کلید امضای انتشار نیز تغییر نکرده است.

## معماری سورس

- `MainActivity.kt`: UI، Navigation، Drawer، فرم‌ها، پروژه‌ها و Export
- `CabinetEngine.kt`: فرمول‌ها و محاسبات مستقل از Android UI
- `Models.kt`: مدل یونیت، Cut List و پروژه
- `ProjectStore.kt`: ذخیره‌سازی و مهاجرت داده نسخه‌های قدیمی
- `version.json`: اطلاعات Update Checker
- `docs/MARKET_DESCRIPTION_FA.md`: متن آماده مارکت‌ها
- `docs/SOURCE_GUIDE.md`: راهنمای فایل‌ها و توسعه

## بروزرسانی و امضا

برای حفظ قابلیت Update:
1. `applicationId` نباید تغییر کند.
2. `versionCode` در هر انتشار باید افزایش پیدا کند.
3. APK پابلیش باید با همان Signing Key خصوصی پروژه امضا شود.
4. فایل Signing Key و Passwordها نباید در ریپوی عمومی قرار بگیرند.

GitHub Actions خروجی Release بدون امضا می‌سازد؛ بسته خصوصی تحویلی شامل Signing Key، `info.txt` و APK امضاشده خواهد بود.
