# دستیار هوشمند کابینتسازی

اپلیکیشن اندرویدی فارسی و Offline-First برای کابینت‌سازها، MDFکارها و کارگاه‌های ساخت کابینت. پروژه از یک ماشین‌حساب ساده در نسخه 1 به یک دستیار تخصصی شامل محاسبات یونیت، مدیریت پروژه، Cut List، بهینه‌سازی برش ورق، گزارش PDF/CSV، Backup/Restore و برآورد مواد و هزینه ارتقا یافته است.

## نسخه فعلی

**3.0.0 — versionCode 30**

Application ID همچنان `com.mdfchi.app` است و Signing Key خصوصی پروژه نیز تغییر نکرده؛ بنابراین نسخه 3 روی نسخه‌های 1.x و 2.x به‌عنوان Update نصب می‌شود و داده‌های محلی قابل مهاجرت/حفظ هستند.

## امنیت Signing و Update

برای حفظ Updateability:
1. `applicationId` نباید تغییر کند.
2. `versionCode` در هر انتشار باید افزایش یابد.
3. همه APKهای پابلیش باید با Signing Key خصوصی ثابت امضا شوند.
4. Signing Key، Password و `info.txt` هرگز وارد ریپوی عمومی نشوند.

GitHub Actions فقط APK Release خام و بدون امضا می‌سازد. بسته خصوصی تحویلی شامل Signing Key، `info.txt`، APK امضاشده، Checksum و گزارش Verify است.
